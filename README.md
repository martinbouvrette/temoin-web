# temoin-web

Le site de l'outil web de la suite Témoin, servi à `temoin.wominute.com`.

Le site ne contient que l'outil. Il ne garde aucune donnée : celles d'un centre vivent dans un fichier, sur le poste de la personne qui s'en sert.

- `essai-fichier.html` — page d'essai : ce que le navigateur d'un poste permet (enregistrer dans un fichier, faire tourner le moteur, chiffrer).
