Essai : ce poste peut-il enregistrer dans un fichier ?

Cette page ne contient aucune donnée et n'envoie rien nulle part. Elle vérifie ce que ce navigateur permet sur ce poste. Suis les étapes dans l'ordre, puis transmets le résultat du bas de la page.

Le fichier d'essai ne contient qu'une phrase. Tu peux le supprimer après.

Les étapes

  1. 1. Créer un fichier d'essai Une fenêtre demande où l'enregistrer. Choisis le Bureau ou Documents.
  2. 2. Écrire de nouveau dans le même fichier Aucune fenêtre ne devrait s'ouvrir : c'est l'enregistrement « comme Word ».
  3. 3. Relire le fichier
  4. 4. Retrouver le fichier après avoir fermé la page Ferme cet onglet, rouvre la même adresse, puis clique ici. Le navigateur peut demander une autorisation.
  5. 5. Télécharger une copie C'est la solution de rechange. Un fichier « essai-copie.txt » devrait arriver dans Téléchargements.
